# Как пользоваться кабинетом редакции

Кабинет позволяет создавать публикации городского сообщества и разбирать предложения читателей без программирования: новости, истории, фотографии, афишу и объявления. Изменения сохраняются в базе на этом компьютере. Сейчас «опубликовать» означает показать материал на локальном сайте; в интернете сайт ещё не размещён.

## 1. Запустить сайт

Сначала попробуйте открыть `http://127.0.0.1:3000`: если всё работает, переходите ко входу. Команды ниже нужны для следующего запуска. Не запускайте одновременно два сервера сайта на порту 3000.

Откройте терминал PowerShell в VS Code и выполните:

```powershell
Set-Location -LiteralPath 'C:\Projects\my-kineshma'
npm.cmd run db:start
npm.cmd run dev
```

`db:start` запускает базу данных, `dev` — сайт. Оставьте терминал с сайтом открытым. Если он уже работает, повторный запуск не нужен.

Откройте [http://127.0.0.1:3000/admin/login](http://127.0.0.1:3000/admin/login). Используйте этот адрес, не заменяя `127.0.0.1` на `localhost`: защита проверяет точное совпадение адреса сайта с настройками.

## 2. Войти первый раз

1. В Проводнике откройте папку `C:\Projects\my-kineshma\storage\private`.
2. Откройте `first-admin.txt` в Блокноте. Там записаны адрес входа, почта и автоматически созданный пароль.
3. В поле «Электронная почта» укажите `admin@my-kineshma.local`.
4. Скопируйте пароль из файла в поле «Пароль», без подписи «Пароль:» и лишних пробелов.
5. Нажмите «Войти в кабинет».

Файл содержит действующий пароль. Он исключён из Git и не выдаётся сайтом, но доступен человеку с доступом к вашей локальной папке. Сохраните данные в своём менеджере паролей и не пересылайте их в общий чат. Если пароль уже менялся, используйте новый файл, указанный командой смены пароля: старый `first-admin.txt` больше не отражает действующий пароль.

При неверных данных появляется общее сообщение об ошибке. После большого числа попыток вход временно ограничивается; подождите несколько минут и повторите.

## 3. Разобраться в разделах

| Раздел | Что в нём делать |
| --- | --- |
| «Обзор» | Смотреть количество материалов, черновиков и заявок на модерации |
| «Публикации» | Находить, открывать, публиковать, скрывать и удалять новости |
| «Входящие заявки» | Проверять предложения читателей, редактировать, одобрять или отклонять |
| «Комментарии» | Просматривать, редактировать и модерировать комментарии и ответы |
| «Категории» | Добавлять и переименовывать темы ленты |
| «Настройки» | Независимо включать проверку публикаций и комментариев |
| «Открыть сайт» | Проверять, что видят посетители |

На узком экране разделы находятся в меню в верхней части страницы. Счётчики показывают ваши записи в базе, а не демонстрационные материалы из `/demo`.

### Настроить модерацию

Откройте [«Настройки»](http://127.0.0.1:3000/admin/settings). Здесь два независимых чекбокса **«Проверять перед публикацией»**:

- Для публикаций жителей проверка **по умолчанию включена**. Присланный материал ждёт решения редакции.
- Для комментариев проверка **по умолчанию выключена**. Новые комментарии и ответы сразу появляются под опубликованным материалом.

Поставьте или снимите нужную галочку и нажмите **«Сохранить настройки»**. Чтобы публикации жителей выходили сразу, также выберите **«Категория для прямых публикаций»**. Без неё выключить проверку публикаций нельзя.

Настройки действуют на новые отправки. Уже ожидающие публикации и комментарии сами не публикуются после снятия галочки: рассмотрите их отдельно во «Входящих заявках» и «Комментариях». При конфликте изменений обновите настройки и повторите свой выбор.

## 4. Создать первую новость и сохранить черновик

1. Нажмите «Создать новость» в обзоре или списке публикаций.
2. При желании введите заголовок, до 180 символов. Он необязателен.
3. Добавьте текст, фотографию или видео. Подойдёт и один символ, и только вложение без текста. Редактор сохраняет обычный текст; вставлять HTML-код не нужно.
4. Выберите категорию в блоке «Публикация». Это обязательное поле. Если подходящей темы нет, сначала создайте её в разделе «Категории».
5. Для вложений нажмите «Выбрать фотографии» или «Выбрать видео» и дождитесь окончания загрузки.
6. Нажмите «Сохранить черновик». Дождитесь сообщения «Черновик сохранён».

Категория обязательна. Заголовок и текст можно оставить пустыми, если есть фотография или видео; полностью пустую публикацию отправить на сайт нельзя. Максимальная длина текста в обычном редакторе — 50 000 символов. В списке материал без заголовка отображается как «Без заголовка»; это служебная подпись, а не автоматически добавленный заголовок.

Черновик доступен только администраторам. Его текст, фотографии и видео, не используемые в опубликованных новостях, не открываются обычному посетителю даже по прямой ссылке. Сам выбор файла ещё не сохраняет всю новость: после загрузки обязательно нажмите кнопку сохранения.

Изменения не сохраняются автоматически. Надпись «Есть несохранённые изменения» напоминает о необходимости сохранить материал. При закрытии или обновлении страницы браузер может спросить, хотите ли вы уйти. Если нужны правки, останьтесь и сохраните их.

## 5. Добавить фотографии и видео

Можно прикрепить до 6 фотографий. Принимаются JPEG, PNG и WebP, до 5 МиБ каждый файл и до 20 мегапикселей. SVG и другие форматы не поддерживаются. Слишком большое фото сначала уменьшите в редакторе изображений.

Первая фотография становится обложкой. Чтобы выбрать другую, нажмите «Сделать обложкой» на нужном изображении. Крестик убирает фотографию из материала; затем сохраните изменение. Неиспользуемые файлы могут остаться в закрытом хранилище, но посетителям не выдаются.

Сервер проверяет фактический формат, преобразует фотографии в WebP и удаляет метаданные. Используйте фотографии, которые вы имеете право публиковать. Новость можно опубликовать без изображения.

Кнопка «Предпросмотр» показывает заголовок, обложку и текст. Чтобы продолжить правки, вернитесь во вкладку «Редактор». Предпросмотр сам по себе ничего не публикует.

Для видео используйте отдельный блок **«Прикреплённое видео»**. Можно загрузить один файл MP4 или WebM до **50 МиБ**, продолжительностью до **10 минут** и размером кадра не более **3840 пикселей по каждой стороне**. Для MP4 поддерживаются H.264 и звук AAC; для WebM — VP8/VP9 со звуком Opus/Vorbis. Видео без звука также допускается.

После загрузки доступен обычный видеоплеер. Нажмите «Убрать видео», чтобы исключить его из материала, или «Заменить видео», чтобы выбрать другой файл; затем сохраните изменения. Прикреплённый файл воспроизводится прямо в ленте и на странице публикации. Видео проверяется и сохраняется в исходном виде, без автоматического удаления его метаданных.

Во время отправки большого файла дождитесь завершения обработки. Сервер прекращает незавершённую загрузку через 90 секунд. Если файл не принимается, уменьшите размер или сохраните его в поддерживаемом формате.

### Указать источник и добавить ссылку на видео

В редакторе публикации есть блок **«Источник и внешняя ссылка»**. Категория отвечает на вопрос «о чём материал», а источник — «откуда он пришёл». Например, сообщение библиотеки может относиться к категории «Афиша» и иметь происхождение «Официальное сообщение».

| Поле | Как заполнить |
| --- | --- |
| «Происхождение публикации» | Выберите «Публикация сообщества», «От жителя», «Официальное сообщение» или «Сторонний источник» |
| «Название источника» | Необязательное публичное название, например «Городская библиотека». До 100 символов |
| «Ссылка на первоисточник» | Необязательная ссылка на исходный материал, начинающаяся с `https://`. До 2048 символов |
| «Ссылка на видео на внешнем сайте» | Необязательная HTTPS-ссылка на страницу видео. До 2048 символов |

У новой публикации по умолчанию стоит «Публикация сообщества». Материал из предложки получает происхождение «От жителя» — при ручном одобрении и при прямой публикации. Публичное имя, которое житель явно указал в новой форме, показывается как имя автора. Приватный контакт и имя из старых заявок не становятся источником и не переносятся на сайт.

«Официальное сообщение» выбирайте явно, если материал действительно пришёл из официального источника. Выбор категории сам эту метку не назначает. Она описывает происхождение публикации и не является автоматическим знаком проверки фактов.

После заполнения сохраните черновик или изменения. Название и ссылка источника будут показаны рядом с публикацией. Ссылка на внешнее видео открывается в новой вкладке; прикреплённый файл из блока «Прикреплённое видео» воспроизводится внутри сайта. Проверяйте, что внешняя ссылка ведёт на нужный общедоступный материал. Адреса с `http://`, логином, паролем или пробелами не принимаются.

Чтобы убрать название, ссылку или видео, очистите соответствующее поле и сохраните изменения. Для смены происхождения используйте выпадающий список. У снятого с публикации материала эти сведения тоже скрыты от обычного посетителя.

## 6. Опубликовать новость

1. Проверьте содержание, категорию и все вложения.
2. Убедитесь, что материал содержит хотя бы заголовок, текст, фотографию, прикреплённое видео или внешнюю ссылку на видео. Минимального количества символов нет.
3. Нажмите «Опубликовать» и дождитесь сообщения об успехе.
4. В блоке публикации нажмите «Открыть на сайте» или откройте [главную страницу](http://127.0.0.1:3000).

После публикации материал получает статус «Опубликовано», появляется в общей ленте и доступен на отдельной странице новости. Если главная была открыта раньше, обновите её. Для проверки прав обычного посетителя можно открыть ссылку в приватном окне браузера.

Если появилась ошибка, не считайте материал сохранённым или опубликованным: исправьте указанные поля и повторите действие. Сайт сообщает об успехе только после ответа сервера.

## 7. Найти и изменить существующую публикацию

В разделе «Публикации» выберите «Все», «Опубликовано», «Черновики» или «Снято с публикации». Для поиска введите запрос и нажмите «Найти». Если материалов много, используйте «Назад» и «Далее» внизу списка.

Нажмите название новости или значок редактирования. Внесите правки и сохраните:

- У опубликованной новости — «Сохранить изменения». Правки будут видны читателям.
- У черновика — «Сохранить черновик» или «Опубликовать».
- У скрытой новости — «Сохранить без публикации» или «Опубликовать».

Не редактируйте одну новость одновременно в нескольких вкладках. Если другой редактор или вкладка уже сохранили её, появится сообщение о конфликте. Скопируйте свои несохранённые правки в отдельный документ, обновите страницу, сравните версии и внесите изменения заново. Защита не позволяет незаметно затереть чужую работу.

## 8. Снять с публикации или удалить

«Снять с публикации» скрывает новость с сайта, сохраняя её в кабинете. Действие требует подтверждения. Если нажать эту кнопку в редакторе, текущие правки также сохранятся. Новость потом можно снова опубликовать.

«Удалить публикацию» удаляет запись без возможности отмены в интерфейсе. Перед удалением появляется подтверждение. Если нужно только временно убрать материал, используйте снятие с публикации.

После снятия или удаления страница новости перестаёт открываться для посетителей. Фото и видео, которые не используются ни в одной опубликованной новости, тоже становятся закрытыми. Уже увиденную или скачанную посетителем копию браузера сайт вернуть не может.

## 9. Управлять категориями

Откройте «Категории», введите название от 2 до 60 символов и нажмите «Добавить категорию». Название должно быть уникальным; регистр букв не создаёт отдельную категорию.

Значок редактирования позволяет переименовать категорию. Удаление доступно только для категории без публикаций, включая черновики и скрытые материалы. Чтобы удалить занятую категорию, сначала перенесите её новости в другую категорию через редактор.

## 10. Разобрать предложенные новости

Посетители отправляют материалы через страницу [«Предложить публикацию»](http://127.0.0.1:3000/suggest-news). Регистрация не требуется. На первом экране достаточно написать текст или выбрать фото/видео; заголовок и контакт раскрываются кнопкой «Дополнительно».

Если проверка публикаций включена, кнопка «Отправить» создаёт заявку **«На модерации»**. Если проверка выключена, кнопка **«Опубликовать»** создаёт запись в ленте с выбранной администратором категорией по умолчанию. Заявка при этом получает статус **«Опубликована»**. Подтверждение формы отражает реальный результат ответа сервера.

Для заявок, ожидающих проверки:

1. Откройте [«Входящие заявки»](http://127.0.0.1:3000/admin/submissions) в меню кабинета. Число ожидающих заявок также видно в «Обзоре».
2. Нажмите на заявку. Проверьте имеющиеся текст, фото и видео. Фото открывается крупнее в новой вкладке, видео можно воспроизвести в кабинете.
3. Отредактируйте материал и выберите категорию. Можно оставить заголовок и текст пустыми при наличии вложения, убрать лишнее фото или видео, выбрать обложку.
4. Для продолжения работы позже нажмите «Сохранить изменения». Заявка останется закрытой от посетителей.
5. Проверьте «Предпросмотр». Когда всё готово, нажмите «Одобрить и опубликовать», подтвердите действие и дождитесь сообщения об успехе.
6. Нажмите «Открыть на сайте» и проверьте новость. Дальнейшие правки выполняйте через «Редактировать публикацию».

Созданный материал будет помечен «От жителя». Чтобы добавить новые вложения, название источника или внешнюю ссылку, откройте «Редактировать публикацию». Статус «Опубликована» сам по себе не означает ручную проверку: материал мог выйти сразу по текущим настройкам.

В форме по умолчанию выбрано **«Анонимно»**. Публичное имя при этом не сохраняется. В варианте **«От своего имени»** житель может указать необязательное имя или псевдоним до 60 символов — оно будет видно читателям. Контакт до 200 символов вводится отдельно через «Дополнительно» и остаётся только редакции, в том числе при анонимной публикации. Если житель не заполнял контакт, он не требуется.

Прежнее приватное поле имени из старых заявок остаётся приватным. В кабинете оно подписано отдельно от публичного имени. Личные сведения, которые житель самостоятельно написал в основном тексте или добавил в фото/видео, проверяйте перед публикацией.

«Отклонить заявку» оставляет её в разделе «Отклонённые». Такую заявку можно пересмотреть, изменить и одобрить позже. «Удалить заявку» удаляет её и сведения об отправителе; удаление одобренной заявки **не удаляет созданную новость**. Снять или удалить новость можно отдельно в «Публикациях».

В предложке допустимы до 4 фотографий по 5 МиБ и одно видео до 50 МиБ. Заголовок — до 180 символов, текст — до 20 000; оба необязательны. Пустая форма без текста и вложений не отправляется. Все данные одного запроса ограничены 72 МиБ, на загрузку отведено 90 секунд. Изменения текущего этапа описаны в [STAGE-3.md](STAGE-3.md).

## 11. Выйти и запустить сайт снова

Нажмите «Выйти из аккаунта» в нижней части меню. Успешный выход завершает сеанс на сервере и возвращает форму входа. Если сервер недоступен и появилось сообщение об ошибке, повторите выход после восстановления связи.

Для остановки сайта нажмите `Ctrl+C` в его терминале. Для остановки базы выполните:

```powershell
npm.cmd run db:stop
```

После перезагрузки компьютера снова выполните `npm.cmd run db:start`, затем `npm.cmd run dev`. PostgreSQL не настроен как автоматически запускаемая служба Windows. Сохранённые публикации останутся в базе.

Не удаляйте `storage` и не запускайте команды сброса базы для устранения ошибки входа или запуска. В этой папке находятся ваши новости, фотографии и файлы доступа.

## Дополнительный администратор и забытый пароль

Эти действия выполняются владельцем проекта в локальном терминале при работающей базе. Публичной регистрации и восстановления через письмо нет.

Для отдельного аккаунта другого редактора:

```powershell
npm.cmd run admin:create
```

Введите почту и имя по запросу. Команда создаст случайный пароль и сообщит путь к отдельному файлу в `storage/private`; пароль не печатается в терминале.

Если пароль забыт или его нужно сменить:

```powershell
npm.cmd run admin:reset
```

Введите почту администратора. Будет создан новый случайный пароль в файле `storage/private/password-reset-….txt`. Все действующие сеансы этого аккаунта завершатся, потребуется повторный вход. Старый пароль перестанет работать. Сами новости при этом не удаляются.

## Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| Страница не открывается | Проверьте запуск `db:start` и `dev`; посмотрите сообщения в терминале |
| Ошибка входа или запрос отклонён | Откройте именно `http://127.0.0.1:3000`, проверьте почту и актуальный пароль |
| Вход временно ограничен | Подождите несколько минут, затем повторите с правильными данными |
| Порт 3000 занят | Проверьте, не работает ли уже сайт; для админки нужен адрес, совпадающий с `APP_URL` |
| Новость не видна на главной | Проверьте статус «Опубликовано», обновите главную и сбросьте её фильтры |
| Предложенная новость не видна на главной | Откройте «Входящие заявки»: сохранение и отправка на модерацию ещё не означают публикацию |
| Фото не принимается | Проверьте формат, размер до 5 МиБ, разрешение до 20 Мп; в редакторе новости лимит 6 фото, в предложке — 4 |
| Видео не принимается | Проверьте MP4/H.264/AAC или WebM/VP8/VP9, размер до 50 МиБ, длительность до 10 минут и кадр до 3840 пикселей по каждой стороне |
| Ссылка источника или видео не сохраняется | Укажите полный `https://`-адрес длиной до 2048 символов, без логина, пароля и пробелов |
| Видео открывается в другой вкладке | Это внешняя ссылка. Для воспроизведения внутри сайта загрузите файл в блоке «Прикреплённое видео» |
| Нельзя выключить проверку публикаций | Выберите существующую категорию для прямых публикаций и сохраните настройки |
| Категория не удаляется | Перенесите все её публикации, включая черновики, в другую категорию |

Перед переносом на другой компьютер или сервер нужны отдельные резервные копии PostgreSQL и фотографий. Автоматическое резервное копирование на этом этапе не настроено; Git не содержит базу и загрузки.
