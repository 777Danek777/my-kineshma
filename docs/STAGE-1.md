## Границы этапа

Главная страница реализована как интерактивное визуальное демо на Next.js App Router. Данные находятся в `src/lib/demo-content.ts`. Все девять текстов демонстрационные и не описывают подтверждённые события Кинешмы. Отметки об этом размещены в верхней полосе, карточках, подборках, диалогах и футере.

Демонстрация включает:

- Тёмную тему с акцентным цветом, локальным шрифтом Manrope и фотографиями настоящей Кинешмы.
- Шапку с логотипом, навигацией, поиском, ссылкой на VK и кнопкой «Предложить новость».
- Верхний панорамный баннер, крупный главный материал и сетку карточек.
- Категории, счётчик найденных материалов, сброс фильтров и пустое состояние.
- Боковые блоки сообщества, подборки, предложки и фотографии города.
- Нижний блок сообщества, футер, информацию о проекте и авторах фотографий.
- Мобильное меню и адаптивную компоновку.
- Диалоги материалов и информационных разделов, фокусируемые кнопки и ссылку перехода к основному содержимому.

Фотографии иллюстрируют макет и не служат подтверждением демотекстов. Авторы, исходные страницы и лицензии перечислены в [IMAGE-CREDITS.md](IMAGE-CREDITS.md); ссылка на авторов предусмотрена в футере.

## Поведение интерфейса

На старте видны шесть карточек. «Показать ещё» раскрывает оставшиеся три. Выбор категории и изменение поискового запроса возвращают лимит к шести карточкам. Поиск применяется одновременно с выбранной категорией, ищет по заголовку, описанию и названию категории, игнорирует регистр, крайние пробелы и различие между «е» и «ё».

Категории переключают локальный набор примеров, а не открывают отдельные страницы. В категории «Происшествия» намеренно нет материалов: она показывает пустое состояние. «Сбросить фильтры» и «Показать все материалы» очищают запрос и возвращают все категории.

Нажатие на карточку, главный материал или материал из боковой подборки открывает диалог с текстом и предупреждением о демоверсии. Его можно закрыть крестиком, клавишей `Escape` или нажатием на фон за пределами содержимого.

«Предложить новость» открывает пояснение: форма ещё не подключена, доступен переход в сообщество. Ссылки VK ведут на `https://vk.ru/my_kineshma` и открываются в новой вкладке. Нажатие этих ссылок не отправляет публикацию автоматически.

Выбранные фильтры и состояние страницы не сохраняются между перезагрузками. На этом этапе нет отдельных URL материалов, серверного поиска или загрузки следующей страницы с сервера.

## Как запустить и открыть

Требуется Node.js 24. В PowerShell:

```powershell
Set-Location -LiteralPath 'C:\Projects\my-kineshma'
npm.cmd install
npm.cmd run dev
```

После сообщения о готовности откройте [http://localhost:3000](http://localhost:3000), при необходимости — [http://127.0.0.1:3000](http://127.0.0.1:3000). Если порт занят, ориентируйтесь на адрес в терминале. Dev-сервер доступен только на этом компьютере. Остановка — `Ctrl+C`.

Проверки кода и production-сборки:

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run build
```

Для просмотра production-сборки остановите dev-сервер, убедитесь в успешном выполнении `build` и запустите:

```powershell
npm.cmd run start
```

Адрес по умолчанию — [http://localhost:3000](http://localhost:3000). Для демо не требуются PostgreSQL, Docker, VK API или `.env`.

Заготовленные каталоги не означают готовность этих модулей.
