# Моя Кинешма

**Моя Кинешма. Город. Люди. События.** Городское интернет-сообщество, связанное с [«Моей Кинешмой» во ВКонтакте](https://vk.ru/my_kineshma): новости, истории жителей, фотографии, афиша и объявления. Работают общая лента, страницы публикаций, лайки, обсуждения, предложка с модерацией и защищённый кабинет редакции с PostgreSQL.

## Текущее состояние

Главная `/` показывает опубликованные материалы. Черновики, ожидающие проверки и снятые с публикации материалы скрыты от посетителей. У публикации есть постоянный адрес `/news/…`. На `/demo` доступны явно обозначенные демонстрационные примеры оформления; эти тексты не являются реальными сообщениями о событиях.

Доступны светлая и тёмная темы: нейтральные поверхности, голубые акценты и стеклянные элементы в шапке, фильтрах и боковых блоках. Баннер стал компактнее. В карточке последовательно показаны автор, время, необязательные заголовок и текст, фотографии или видео, действия и комментарии. Длинный текст раскрывается кнопкой «Показать ещё», фотографии открываются в галерее без обрезания пропорций, загруженное видео воспроизводится встроенным плеером. Сохранены поиск и фильтры темы, источника и формата.

Переключатель темы есть в публичной шапке, кабинете и на странице входа. Выбор сохраняется в браузере и синхронизируется между вкладками. При первом визите включена тёмная тема; ранее сохранённый выбор светлой темы остаётся в силе. Настройка оформления не меняет модерацию и данные сайта. Итоговая сборка темы, TypeScript, ESLint и проверка серверной разметки прошли; визуальная проверка обычного браузера выполняется отдельно. Механизм, ограничения и результаты — в [руководстве по темам](docs/THEMES.md).

Лайки и комментарии работают без регистрации читателей. Под карточкой видны последние обсуждения; там же можно написать комментарий, ответить или поставить лайк комментарию. «Обсудить» раскрывает обсуждение внутри публикации. Раздел `/admin/comments` позволяет одобрять, отклонять, редактировать и удалять сообщения. В меню «Поделиться» доступны копирование ссылки, VK, Telegram и системное меню поддерживаемого устройства. Счётчики берутся с сервера; фиктивной активности и количества репостов нет.

Имя в комментарии и ответе необязательно: без него появляется подпись «Житель Кинешмы». Можно выбрать «С именем» и указать псевдоним от 2 до 60 символов. Явный мат и известные оскорбительные слова в псевдонимах отклоняются сервером, в том числе при редактировании администратором и выборе публичного имени в предложке. Правила и проверки — в [SOCIAL.md](docs/SOCIAL.md).

В кабинете доступны публикации, черновики, входящие заявки, комментарии, категории и настройки. В редакторе можно прикрепить фотографии и видео, указать происхождение материала и ссылку на первоисточник. Сохранённая внешняя ссылка на видео по-прежнему открывается на сайте автора. Публичной регистрации администраторов нет.

Форма `/suggest-news` принимает текст любой непустой длины, фотографии, видео или их сочетание. Заголовок, имя и контакт необязательны. Можно отправить только фотографию или один символ текста. Выбор «От своего имени» позволяет указать публичное имя или псевдоним; «Анонимно» скрывает имя. Контакт из раздела «Дополнительно» доступен только редакции, в том числе если посетитель сам решил оставить его при анонимной отправке.

В `/admin/settings` независимо переключаются две проверки: **по умолчанию комментарии появляются сразу, публикации жителей сначала проходят модерацию**. Для прямой публикации материалов нужно выбрать категорию по умолчанию. Настройки применяются к новым отправкам: уже ожидающие материалы и комментарии сами не публикуются. Подробные шаги читателя и редактора — в [руководстве обновления](docs/COMMUNITY-UPDATE.md).

К исходным девяти категориям добавлены «Развлечения», «Фото города» и «Интересное». Категории по-прежнему управляются через кабинет редакции.

Сайт работает только на этом компьютере. Размещение в интернете, домен, HTTPS и автоматические резервные копии ещё не настроены. Вход через VK и получение имени/контактов из VK не подключены: для этого потребуется отдельная настройка приложения и ключей. Обычная ссылка на сообщество и меню распространения в VK уже есть. Индексация поисковиками пока отключена.

## Локальный запуск

Сначала откройте `http://127.0.0.1:3000`: если сайт уже работает, повторно запускать его не нужно. Приведённые ниже команды — для запуска в режиме разработки. `dev` и `start` нельзя одновременно запускать на одном порту 3000.

В PowerShell:

```powershell
Set-Location -LiteralPath 'C:\Projects\my-kineshma'
npm.cmd run db:start
npm.cmd run dev
```

Оставьте терминал с сайтом открытым. Используйте именно `127.0.0.1`, соответствующий текущему `APP_URL`:

- [Сайт](http://127.0.0.1:3000).
- [Вход в кабинет редакции](http://127.0.0.1:3000/admin/login).
- [Предложить публикацию](http://127.0.0.1:3000/suggest-news).
- [Входящие заявки редакции](http://127.0.0.1:3000/admin/submissions).
- [Модерация комментариев](http://127.0.0.1:3000/admin/comments).
- [Настройки модерации](http://127.0.0.1:3000/admin/settings).
- [Демонстрация оформления сообщества](http://127.0.0.1:3000/demo).

Первый администратор: `admin@my-kineshma.local`. Случайный пароль сохранён в локальном файле `storage/private/first-admin.txt`, исключённом из Git. Откройте его на своём компьютере; не публикуйте содержимое. Подробные действия — в [руководстве редактора](docs/ADMIN.md).

PostgreSQL не установлен как служба Windows: после перезагрузки снова выполните `db:start`. Для остановки сайта нажмите `Ctrl+C`, затем при необходимости выполните `npm.cmd run db:stop`. Не удаляйте `storage`: там находятся база, фотографии, видео и локальные секреты.

## Команды разработки

Нужны Node.js 24 и npm. На текущем компьютере зависимости и `.env` уже настроены. На новом компьютере потребуется отдельно подготовить PostgreSQL и настройки по `.env.example`; одного копирования кода недостаточно.

```powershell
npm.cmd ci
npm.cmd run db:generate
npm.cmd run db:migrate
npm.cmd run db:seed
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run build
```

`db:migrate` применяет подготовленные миграции, `db:seed` добавляет начальные категории. Они не заменяют резервное копирование. Команды сброса существующей базы для запуска не нужны.

Для просмотра production-сборки после успешного `build` остановите dev-сервер и выполните `npm.cmd run start`. Адрес остаётся `http://127.0.0.1:3000`, база должна работать.

Для обновлённой формы, настроек модерации и загружаемых видео используется `npm.cmd run test:composer`. Команда `npm.cmd run test:social` проверяет лайки, комментарии, ответы и модерацию. `npm.cmd run test:metadata` проверяет поля источника, внешние ссылки и закрытость черновиков. `npm.cmd run test:admin` и `npm.cmd run test:submissions` проверяют кабинет и предложку; эти сценарии также актуализированы под текущий этап.

Интеграционные проверки работают против запущенного локального приложения, создают собственные временные данные и очищают их. Запускайте их последовательно: они намеренно расходуют общие антиспам-лимиты. Проверки переключателей сохраняют исходные настройки и восстанавливают их после сценария. Общие лимиты сбрасывать не нужно.

`npm.cmd run test:display-name` проверяет подпись без имени, нормализацию и фильтр псевдонимов без запуска сайта и обращения к базе. Все 7 групп прошли. Новые сценарии имён также прошли на свежем production-сервере в составе `test:social` и `test:composer`.

## Проверенное состояние

Последнее обновление необязательного имени проверено на свежем production-сервере: **social — 38/38, composer — 15/15**, а чистые проверки имён прошли **7/7**. Общие TypeScript, ESLint и production-сборка прошли; проверки темы — 4/4. Визуальная браузерная проверка последних изменений пока не подтверждена. Подробности новых сценариев — в [SOCIAL.md](docs/SOCIAL.md).

Ранее для обновления ленты были выполнены 108 групп: composer — 13, social — 34, admin — 24, submissions — 25, metadata — 12. Результаты того этапа, включая видео и мобильную форму, сохранены в [отчёте обновления](docs/COMMUNITY-UPDATE.md#проверки).

Новые автоматические сценарии очистили собственные временные записи и восстановили прежние настройки модерации и категорию по умолчанию. Рабочие материалы владельца сохранены: база не обнулялась, общие антиспам-счётчики не сбрасывались.

| `src/app/(site)/`, `src/app/(site)/demo/` | Публичные страницы и демонстрационный макет |

| `src/server/submissions/`, `src/components/admin/submissions-*.tsx` | Антиспам-проверка и модерация |
| `src/server/social/`, `src/app/api/posts/[slug]/`, `src/components/community/publication-comments.tsx` | Лайки, обсуждения, анонимный идентификатор и ограничения |
